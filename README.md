## 📖 About Us

**Sri Veerabhadra Nursery & Gardens** is a family-owned nursery located in **Burrilanka, Kadiam** — the heart of India's famous nursery belt in **East Godavari, Andhra Pradesh**. With roots in agriculture spanning generations, the family converted their fruit garden into a professional nursery in **2005**.

Today, we cultivate **200+ plant varieties** across **15 acres**, serving clients throughout India — from individual home gardeners to large-scale landscape developers, farmhouse owners, resorts, and government projects.

> *"Every healthy plant contributes to a greener future."*

## 🏗️ Website Structure

This is a **Phase 1 static website** built with pure **HTML**, **CSS**, and **JavaScript** — no frameworks, no CMS, no database.

```
📂 Sri Veerabhadra Nursery
│
├── 🏠 index.html              ← Homepage with hero, categories, featured plants
├── 🌱 plants.html             ← Full plant catalog with search & filters
├── 🔍 plant-detail.html       ← Individual plant detail page
├── 📝 blog.html               ← Blog listing page
├── 📖 blog-detail.html        ← Full blog article view
├── 👥 about.html              ← Company story, team, and values
├── 📞 contact.html            ← Contact form, phone, WhatsApp, map
│
├── 📦 plants.json             ← Plant data (52 entries)
├── 📦 blogs.json              ← Blog data (6 articles)
├── 🛠️ update-data.js          ← CLI tool to manage plant/blog data
│
├── 📂 assets/
│   ├── 📂 css/style.css       ← Complete stylesheet
│   ├── 📂 js/main.js          ← Core JavaScript logic
│   └── 📂 images/
│       ├── 📂 plants/         ← 52 plant images (.webp)
│       ├── 📂 blog/           ← Blog featured images
│       ├── 📂 categories/     ← Category card images
│       ├── 📂 team/           ← Team member photos
│       └── 📂 general/        ← Misc assets
│
├── 🤖 robots.txt              ← SEO crawl rules
└── 🗺️ sitemap.xml             ← XML sitemap for search engines
```

## 🛠️ Data Management Tool

A built-in **Node.js CLI** ([update-data.js](update-data.js)) for managing plant and blog content:

```bash
# List all plants grouped by category
node update-data.js plant list

# Add a new plant interactively
node update-data.js plant add

# Edit a plant's details
node update-data.js plant edit "Flame Tree"

# Remove a plant
node update-data.js plant remove "Flame Tree"

# List all blog posts
node update-data.js blog list

# Run data quality audit
node update-data.js audit
```

> No external dependencies required — runs with Node.js built-in modules only.

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/vvsnmurthy3758/sriveerabhadranursery.git
   cd sriveerabhadranursery
   ```

2. **Open in browser**
   ```
   Open index.html directly in your browser
   — or —
   Use a local server (e.g., Live Server in VS Code)
   ```

3. **Manage data** (requires Node.js)
   ```bash
   node update-data.js plant list
   node update-data.js audit
   ```
